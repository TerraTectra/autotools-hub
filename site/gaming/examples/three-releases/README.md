# Три релиза локализации: собственный учебный пример

«Учебная станция» — вымышленный набор интерфейсных строк, не выпущенная игра и не заказ клиента. Все английские и русские строки созданы для демонстрации с помощью ИИ; профессиональная редактура и игровой запуск не проводились.

v1: 23 текстовые строки. v2: 25. v3: 25. В папке каждой версии есть en.json и актуализированный ru.json.

При переходе v1 → v2 используйте v1/en.json, v2/en.json и v1/ru.json. После изучения отчёта повторите с v2/ru.json. При переходе v2 → v3 используйте v2/en.json, v3/en.json и v2/ru.json, затем v3/ru.json.

Полный список контекстных решений находится в decisions.json. Пример не доказывает качество перевода для другой игры. Удалённые строки здесь исключены осознанно для вымышленного сценария: реальный проект может продолжать использовать их для совместимости.

Бесплатный проверщик: https://terratectra.github.io/autotools-hub/site/gaming/localization-check/ — режим «Локализацию после обновления».

Отчёты before/after лежат в reports. Нулевые структурные расхождения после обновления не закрывают проверку смысла, шрифтов и экранов. Изменения оригинала сохраняются в списке даже после актуализации перевода.

В скачиваемом архиве находится checker-core.js 1.1 и тот же verify-example.cjs. Запуск: node verify-example.cjs. В репозитории скрипт использует ../../localization-check/checker-core.js. Повторный запуск проверяет результат, но не переписывает опубликованные отчёты; их создание выполняется с --write.

benchmark.json измеряет только автоматическую обработку файлов и сравнение, без редакторского труда и игровой проверки. Это одиночный замер конкретной среды, не обещание производительности или срока коммерческой задачи.

manifest.json содержит SHA-256 учебных файлов. ZIP состоит из собственных JSON, отчётов, исходника проверщика и документации; игровые бинарные файлы и чужие моды отсутствуют.

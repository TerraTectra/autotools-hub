# TerraTectra Localization Check 1.1

Бесплатное структурное сравнение двух UTF-8 JSON-файлов локализации, полностью в браузере. Никаких внешних скриптов, запросов с содержимым файлов, сохранения в localStorage или отправки на сервер.

Проверяет текстовые листья вложенных объектов и массивов: отсутствующие ключи, тип значения, пустой перевод, простые `{name}` / `{0:format}` подстановки, printf и состав тегов. Лишние ключи и совпадение с оригиналом — предупреждения. Пути представлены как JSON Pointer; символы `~` и `/` экранируются, поэтому разные структуры не сливаются.

Границы: до 1 МиБ UTF-8 на документ, 20 000 узлов, 40 уровней. Не проверяет смысл текста, шрифты, игровой контекст, вложенность тегов, ICU, пользовательские языки шаблонов и повторяющиеся ключи JSON. Встроенный пример — собственные вымышленные строки. Это инструмент первичной диагностики, не сертификация готовности русификатора.

Редактирование сбрасывает результат и возможность скачать отчёт. Отчёт содержит актуальные обнаруженные пути и технические маркеры; пользователь самостоятельно решает, кому его передавать.

Режим обновления принимает предыдущий оригинал, текущий оригинал и проверяемый перевод. Он показывает новые, изменённые и удалённые текстовые листья по точному пути и исходному тексту, включая уже переведённые новые строки. Изменённый исходник требует ручной проверки смысла даже при нулевых структурных ошибках. Перевод не переписывается, ключи не удаляются, ручная приёмка не определяется автоматически. Отчёт этого режима содержит полный текст изменённых строк и соответствующие значения перевода.

JSON Pointer массива сравнивается по индексу: перестановки и переименования не распознаются. Пробелы тоже считаются изменением. Переход строка → число считается удалением текстовой строки, число → строка — добавлением. Пустые контейнеры и другие нетекстовые значения не проверяются как схема проекта.

Экспорт ядра: `compare(source, translation)` и `compareUpdate(previousSource, source, translation)`. Собственный пример и руководство: `../guides/localization-update/`.

Запуск проверки ядра: `node checker.test.cjs`.
